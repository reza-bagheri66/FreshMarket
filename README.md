# 🛒 FreshMarket

A hyper-local multi-vendor e-commerce platform built with Python & Django.

## ✨ Features
* **Multi-Vendor Management:** Showcase local stores and their products.
* **Dynamic Cart:** Session-based shopping cart system.
* **Order Processing:** Seamless checkout and order management flow.

## 🛠️ Tech Stack
* Python 3
* Django
* SQLite
* HTML5 / CSS3
